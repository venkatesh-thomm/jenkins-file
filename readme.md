## Jenkins Pipelines (In Short)

### Declarative Pipeline

* DSL built on top of Groovy in Jenkins
* Structured (pipeline → stages → steps)
* Syntax & structure validated before execution
* Easy to read, maintain, and standardize

### Scripted Pipeline

* Pure Groovy scripting
* Runs line-by-line at runtime
* More flexible and powerful
* Requires manual error handling (try/catch)

### Key Difference

* **Declarative** → Structured + safer
* **Scripted** → Flexible + more control
